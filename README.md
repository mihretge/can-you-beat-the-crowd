# Can You Beat the Crowd?

## Start on Windows
1. Extract this ZIP into a folder.
2. Double-click `START_APP.bat`.
3. Wait while it installs the required packages and opens the app in your browser.
4. Keep the black Command Prompt window open while using the app.

## Important
This first step runs the app on your own computer. To let colleagues use a QR code from their phones, the app must then be published online. Test the app before using it at the huddle.
