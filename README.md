# Can You Beat the Crowd? 🎯

An interactive game designed for huddles and team activities. Test your instincts, make your guesses, and see whether you can beat the crowd!

## 🎮 Play the Game

The game will be available online once deployed. A public link can be shared with colleagues, allowing them to participate using their phones or computers.

## 🚀 How to Play

1. Open the game using the shared link or scan the QR code.
2. Follow the instructions displayed on the screen.
3. Submit your answers and see how you compare with the crowd.
4. Have fun!

## 🛠️ Technologies

- Python
- Streamlit
- Pandas
- QR Code generation (`qrcode`)

## 💻 Run Locally

1. Clone this repository.
2. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the application:

   ```bash
   streamlit run app.py
   ```

## 🌐 Deployment

This application can be deployed using [Streamlit Community Cloud](https://share.streamlit.io/).

Once deployed, share the public app URL or generate a QR code linking to it so colleagues can join from their devices.
